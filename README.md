# Handwritten Digit Recognition using Deep Learning

## Project Overview

This project uses Deep Learning to recognize handwritten digits from 0 to 9 using the MNIST dataset.

## Objective

The objective is to build a neural network that can identify handwritten digits from grayscale images.

## Technologies Used

* Python
* Google Colab
* TensorFlow and Keras
* NumPy
* Matplotlib
* MNIST Dataset

## Methodology

1. Load the MNIST dataset.
2. Visualize sample handwritten digit images.
3. Normalize image pixel values.
4. Build a neural network using TensorFlow and Keras.
5. Train the model for 5 epochs.
6. Evaluate the model on test data.
7. Predict a handwritten digit.

## Model Architecture

* Flatten Layer
* Dense Layer with 128 neurons and ReLU activation
* Output Layer with 10 neurons and Softmax activation

## Results

The model achieved approximately 97% test accuracy in my run.

## How to Run

1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. View the model accuracy and digit prediction.

## Conclusion

This project demonstrates how deep learning can be used for handwritten digit recognition using a neural network.
